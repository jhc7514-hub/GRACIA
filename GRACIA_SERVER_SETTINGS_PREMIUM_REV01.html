01 / CORE SETTINGS

기본 환경 · 계정 · 배율

GRACIA SERVER · OFFICIAL GUIDE

SECTION 01.01

계정 및 기본 시스템

  • 일반 플레이: 1인 최대 4계정 허용
  • 버프 지속시간 16시간 · 스킬 자동 습득 · 네비트 및 활력 시스템 삭제
  • 혈맹 가입 또는 직접 창설 필수. 무혈 상태의 쟁 금지
  • 그레이드 패널티 적용 · 프레야의 망토 착용 조건 삭제
  • 바운티 헌터 크리에이트 스킬 습득 가능. 습득되지 않으면 재접속(리스) 후 확인
SECTION 01.02

경험치 및 드랍 배율

  • 일반회원: 경험치 ×3 (파티 ×3.5), 드랍 ×2, SP ×3, 스포일 ×1.5
  • 프리미엄회원: 경험치 ×6, 드랍 ×3, SP ×6, 스포일 ×3
  • 프리미엄 문의: 디스코드 DM
  • 몬스터와의 레벨 차이는 최대 9레벨까지 경험치 획득 가능
  • 파티 경험치: 레벨 차이 20까지 100%, 21~25는 30%, 26 이상은 0%
SECTION 01.03

접속 보상 · 편의 기능

  • 게임 접속 5분마다 GRACIA 서버 포인트 15점 지급
  • 기란 마을 NPC에서 S급 방어구·무기·정령탄·금괴·참여증표 구매 가능
  • 자동사냥: 인게임 명령어 .자동 또는 아드레날린 등 허용
  • 타워(Tower) 프로그램은 절대 사용 금지
  • 네크로폴리스·카타콤 자동사냥 시 원거리 체크 해제 후 진행
  • 장비 제작 및 공방 활성화. 주재료·레시피는 사냥, 기초재료·레시피는 기란 마을 판매
02 / ENCHANT & ITEMS

강화 · 아이템 · 편의 서비스

GRACIA SERVER · OFFICIAL GUIDE

SECTION 02.01

강화 시스템

  • 안전 강화 +3
  • 일반 인챈트 최대치: 무기 +20 / 방어구·액세서리 +15
  • 후원 인챈트 최대치: 무기 +25 / 방어구·액세서리 +20
  • 스킬 인챈트 주의: 풀인챈 상태에서 추가 클릭 시 레벨 1로 초기화, 복구 불가능
  • 개미 반지·프린테사 목걸이·코어 반지 강화 가능, S등급으로 변경
SECTION 02.02

아이템 제작 및 교환

  • 참여증표(이벤트 보스·주간 보스·사냥 획득)와 축제의 아데나로 엘레기아 세트 교환 가능
  • 축복받은 리미티드 파이널 방어구: PvP 방어력 5% 적용
  • 축복받은 리미티드 파이널 방어구 교환 시 속성작 랜덤 변경 및 보석 종류별 300개 추가 지급
  • ALT+B 드레스미 게시판에서 외형 변경 가능 (1만 아데나)
SECTION 02.03

디스코드 신청 서비스

  • 토큰 망토 이동: 올림피아드 토큰으로 구매한 거래 불가 망토를 계정당 1회 이동 지원
  • 리미티드 재료 이동: 인벤토리 내 재료 수량 캡처 후 디스코드에 신청
03 / BOSS & REWARDS

주간 보스 · 이벤트 보스

GRACIA SERVER · OFFICIAL GUIDE

SECTION 03.01

참여증표 획득

  • 주간 보스 및 서버 이벤트 보스 참여 시 참여증표가 인벤토리로 지급
  • 반드시 보스를 최소 1회 직접 타격해야 참여증표 지급
  • 참여증표 거래 가능
  • 부캐릭터도 각각 1회 타격하면 참여증표 획득 가능 (다른 계정 제한 규정 준수)
  • 참여증표는 사냥으로도 획득 가능
SECTION 03.02

주간 오르펜 레이드

  • 주간 이벤트 보스 오르펜: 매주 1회 처치 가능
  • 월요일~일요일 사이 원하는 요일에 진행 가능
  • 서버 재부팅 후 재등장해도 해당 주간에 다시 처치할 수 없음
  • 디스코드 ‘주간-이벤트보스’ 게시판에 기존 이벤트 보스와 동일하게 글 작성
04 / DAILY INSTANCE

1일 던전 · 입장 및 공략

GRACIA SERVER · OFFICIAL GUIDE

SECTION 04.01

입장 조건

  • 최소 2인 이상 · 최소 85레벨 · 파티장만 입장 신청 가능
  • 최대 4계정 허용, 계정당 1캐릭터만 입장 가능
  • 1일 1회 제한 · 퀘스트 없이 입장
  • 동일 IP 입장 가능
  • 입장 성공 시점부터 24시간 재입장 불가
  • 재입장 가능 시간 확인: /인스턴트존
  • 던전 제한시간 60분
SECTION 04.02

공략 핵심

  • 궁수형 몬스터는 물리 방어가 높으므로 격수 + 궁수 조합 추천
  • 마지막 보스들은 거의 동시에 처치해야 하며, 시간차가 크면 부활
  • 엘레기아 +10 세트·2차 무기 +15 기준으로 테스트 완료
  • 보상이 좋은 만큼 난이도는 높게 설정
SECTION 04.03

던전 보상 및 드랍

  • 참여증표 · 축제의 아데나 · 망토교환코인 · 올림피아드 토큰
  • 아데나 · 금괴 · 안타라스·발라카스·슬레이어 재료
  • 일반 몬스터: 참여증표 1~5개 랜덤 드랍
05 / BATTLE RULES

PvP · 전장 · 계정 제재

GRACIA SERVER · OFFICIAL GUIDE

SECTION 05.01

경쟁 콘텐츠 계정 규정

  • 팀배틀·올림피아드·공성전은 1인 1계정만 참여
  • 동일인이 여러 계정으로 참여하면 경고 없이 밴 처리
  • 사랑의 돼지 이벤트는 1인 1캐릭터 필수, 위반 시 계정 정지 및 밴
SECTION 05.02

사냥터 및 PvP 규정

  • 근거리 사냥터에서 원거리 사냥 금지, 원거리 사냥터에서 근거리 사냥 금지
  • 클래스 및 무기 일치 필수, 소환수(소하)는 근거리 취급
  • 쌍방 전쟁 선포 전 공격 금지
  • PvP 지역 외 무분별한 PK 금지
  • 무혈 상태 쟁 금지: 혈맹 가입 또는 창설 필수
  • Non-PvP 존 유저의 PvP 존 사냥 금지 (사냥터 이동 시 번복 불가)
  • 경쟁 레이드는 PvP 존에서 진행
SECTION 05.03

지배의 전장 · 최후의 전장

  • 전장 내 소환, 자유 텔레포트 등록, 리스(재접속) 및 모든 스킬 사용 금지 — 아데나를 지불한 재입장만 허용
  • 위반 시 1차 7일 정지, 2차 영구 정지
  • 지배자의 전장: 서버 모든 유저 입장 가능
  • 최후의 전장: 중립 혈맹만 입장 가능 (쟁 혈맹 입장 불가), PvP 가능
  • 최후의 전장 바이움을 깨우면 전장이 열리지 않으므로 절대 깨우지 말 것

이벤트 · 신규 지원 · 패치

GRACIA SERVER · OFFICIAL GUIDE

주요 이벤트 및 신규 지원
