INSTALL GUIDE V1.1
⬇ 클라이언트 다운로드설치 방법 보기
STEP 01

클라이언트 다운로드

아래 버튼을 누르면 Google Drive에 업로드된 PURE_SERVER_PACKAGE_V1.0.zip 파일로 이동합니다.

파일 크기: 약 13.16GiB (약 14.14GB)　압축 해제 후: 약 26.9GiB

Google Drive 다운로드 페이지 열기 ↗
다운로드 전 디스크 여유 공간을 확인하세요. ZIP 파일과 압축 해제 파일을 동시에 보관할 경우 약 42GiB 이상이 필요하며, 여유 있게 50GB 이상을 권장합니다. Google Drive에서 대용량 파일 바이러스 검사를 할 수 없다는 안내가 표시될 수 있습니다. 배포자가 제공한 파일인지 확인한 후 진행하세요.
STEP 02

ZIP 압축 해제 및 설치

01

ZIP 다운로드

다운로드한 PURE_SERVER_PACKAGE_V1.0.zip 파일을 찾습니다.

02

압축 해제

파일을 마우스 오른쪽 클릭하고 '모두 압축 풀기' 또는 7-Zip의 압축 풀기를 선택합니다.

03

런처 실행

압축을 푼 폴더에서 PURE_LAUNCHER_V1.2.exe를 실행합니다.

※ 서버 설치나 Java 설치는 필요하지 않습니다. 배포받은 클라이언트와 런처만 사용합니다.

📁 PURE_SERVER_PACKAGE_V1.0
📁 PURE_CLIENT
📁 systemH5
▣ l2.exe
🟨 PURE_LAUNCHER_V1.2.exe　← 실행
📄 PURE_NOTICE.txt
📄 PURE_CONFIG.txt
설명용 폴더 구조 그림입니다. 실제 폴더 이름은 압축을 푼 위치에 따라 다를 수 있습니다.
STEP 03

PURE 런처 최초 설정

① 게임 폴더 선택

런처를 실행하고 게임 폴더 선택 기능을 이용해 l2.exe가 들어 있는 systemH5 폴더를 지정합니다.

폴더 찾아보기 — □ ×
📁 압축 해제 폴더
📁 PURE_CLIENT
📁 systemH5　✓ 선택
▣ l2.exe
설정 방법을 설명하기 위한 예시 그림입니다. 실제 Windows 폴더 선택 창과 모양은 다를 수 있습니다.
중요: PURE_CLIENT 폴더 자체가 아니라 systemH5 폴더를 선택해야 합니다.

② 서버 상태 및 게임 시작

폴더를 선택한 후 런처에서 서버 상태를 확인하고 GAME START를 누릅니다.

한 번 선택한 게임 경로는 런처 설정 파일에 저장되므로 다음 실행부터는 다시 선택하지 않아도 됩니다(정상 저장된 경우).

STEP 04

게임 접속 및 월드 입장

런처 실행→SERVER ONLINE 확인→GAME START→게임 로그인→캐릭터 선택 및 월드 입장

서버가 점검 중이거나 운영 PC가 꺼져 있다면 접속되지 않을 수 있습니다. 계정 생성 및 로그인 방식은 서버 운영자의 별도 공지를 따르세요.

SUPPORT

자주 발생하는 문제

런처에서 l2.exe가 없다고 표시됩니다.

폴더를 잘못 선택한 경우가 많습니다. PURE_CLIENT 내부의 systemH5 폴더를 선택하고, 해당 폴더에 l2.exe가 있는지 확인하세요.

SERVER OFFLINE으로 표시됩니다.

서버가 실행 중인지 운영자 공지를 확인하고 인터넷 연결을 점검하세요. 방화벽 또는 보안 프로그램 차단 여부도 확인하되, 보안 기능을 무조건 끄지는 마세요.

GAME START를 눌러도 실행되지 않습니다.

압축 해제가 끝났는지, systemH5 안에 l2.exe가 있는지 확인하세요. 오류 메시지가 있다면 화면을 캡처해 운영자에게 전달하세요.

Google Drive에서 다운로드가 안 됩니다.

파일 공유 권한이 '링크가 있는 모든 사용자 - 뷰어'인지 운영자에게 확인하세요. 다운로드 제한이 발생한 경우 잠시 후 재시도해야 할 수 있습니다.

게임 실행 후 로그인할 수 없습니다.

서버 운영 상태, 계정 정보 및 네트워크 연결을 확인하세요. 계정이나 비밀번호를 타인에게 전달하지 마세요.
